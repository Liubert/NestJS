    Build the complete endpoint inventory per D-05. For every backend controller file:

    1. Extract each route by reading @Get/@Post/@Patch/@Put/@Delete decorators and the controller prefix (@Controller('path')).

    2. For each route, determine consumer(s) by searching:
       - **Admin UI**: grep `admin-ui/src/` for matching API path strings (e.g., `/auth/login`, `/translations/projects`, `/mcp-prompts`, `/mcp-tokens`, `/users`)

       - **Public API**: routes without @UseGuards(JwtAuthGuard) that serve translation JSON (Locize-compatible endpoints)
       - **Internal**: health endpoints consumed by Docker healthcheck or CI scripts

    3. Classify each route:
       - `active` — has at least one confirmed consumer
       - `orphan` — no consumer found in Admin UI, MCP server, or public API
       - `flagged` — partial feature (endpoint exists but feature is incomplete per D-08)

    4. Write `.planning/ENDPOINT-INVENTORY.md` with this structure:

       ```
       {For each flagged route: what's incomplete, is it 90%+ done per D-08}

       {Per D-02: flag entire modules like files/ if no endpoints have consumers, but do NOT recommend deleting the module — only individual endpoints}
       ```
