## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap inside QualityBadge inline flex row |
| sm | 8px | Gap between filter controls in FilterBar |
| md | 16px | Content area horizontal padding (inside table cells) |
| lg | 24px | Page content margin (App.tsx: `margin: '24px 16px 0'`) |
| xl | 32px | Layout section breaks |
| 2xl | 48px | Major vertical spacing between page sections |
| 3xl | 64px | Page-level spacing (not used in this phase) |

Exceptions:
- QualityBadge dot size: 12px width/height (not on the spacing scale — this is a visual diameter, not a layout gap)
- Touch/click targets for Popconfirm triggers: minimum 24x24px clickable area around badge dots

Source: Ant Design 8-point grid; xs exception confirmed by RESEARCH.md Pattern 3.

## Color

**Quality state color palette (fixed, locked by D-02 and D-03):**

| State | Color | Hex | Usage |
|-------|-------|-----|-------|
| checked — green level | Success green | `#52c41a` | Dot + score text for high-quality checked translations |
| checked — yellow level | Warning amber | `#faad14` | Dot + score text for review-needed translations |

| skipped | Primary blue | `#1677ff` | Dot + "skip" label; score=100 by default |
| expected | Primary blue | `#1677ff` | `CheckCircleOutlined` icon; manually accepted |
| failed | Warning orange | `#fa8c16` | `WarningOutlined` icon + "fail" label; system error, NOT quality judgment |
| not_checked | Light gray | `#d9d9d9` (dot), `#bbb` (text) | Gray dot + "—" label; pending state |
| queued / processing | Mid gray | `#8c8c8c` | `SyncOutlined spin` icon; transient in-progress state |

**Accent reserved for:** Primary action buttons (Add Key, Save, AI Translate), skipped/expected quality badge indicator, Sort dropdown active selection highlight, focused form inputs. NOT used for table row hover, informational text, or neutral UI chrome.

## Interaction Contracts

### QualityBadge visual states

Each locale cell in the table renders a QualityBadge after the value text. Layout: `display: inline-flex`, `alignItems: center`, `gap: 4px`.

| reviewState | Visual | Interaction |
|-------------|--------|-------------|
| `not_checked` | 12px gray dot (`#d9d9d9`) + "—" text (`#bbb`, 11px) | Tooltip: "Not yet reviewed". No click action. |
| `queued` | `SyncOutlined spin` (12px, `#8c8c8c`) | Tooltip: "Queued for review". No click action. |
| `processing` | `SyncOutlined spin` (12px, `#8c8c8c`) | Tooltip: "Reviewing...". No click action. |
| `skipped` | 12px blue dot (`#1677ff`) + "skip" text (`#1677ff`, 11px) | Tooltip: "Quality check skipped — scored 100 by default". No click action. |
| `expected` | `CheckCircleOutlined` (12px, `#1677ff`) | Tooltip: "Manually accepted — score: 100/100". Click opens Popconfirm to unmark. |
| `failed` | `WarningOutlined` (12px, `#fa8c16`) + "fail" text (`#fa8c16`, 11px) | Tooltip: "Quality review failed — will retry". No click action. |
| `checked` (green) | 12px green dot (`#52c41a`) + score number (11px, `#52c41a`) | Tooltip: "Score: N/100 — [comment]". Click opens Popconfirm to mark as expected. |
| `checked` (yellow) | 12px amber dot (`#faad14`) + score number (11px, `#faad14`) | Same as checked/green. |
| `checked` (red) | 12px red dot (`#ff4d4f`) + score number (11px, `#ff4d4f`) | Same as checked/green. |

### Table layout

- Table prop: `size='small'` (already set; no change)
- Key column: fixed width 200px, `Typography.Text` with `ellipsis={{ tooltip: true }}`
- Locale value column: width 140–150px, `Typography.Text` with `ellipsis={{ tooltip: fullValue }}`, font-size 12px
- Quality badge column per locale: width 60–70px, `inline-flex` badge (dot + text), no wrap
- Actions column: fixed width 80px

At ≥1280px viewport: all columns fit without horizontal scroll for up to 4 locales. For >5 locales: graceful horizontal scroll fallback (D-10).

### FilterBar layout

Ant Design `Space` with `wrap` prop. Order: Namespace select → Search input → Quality filter select → Sort select → Add Key button (right-aligned).

- Quality filter: `Select` with `mode='default'` (single selection), 180px wide, placeholder "Filter by quality"
- Sort: `Select` 160px wide, default value "Sort: Key"

### Sort behavior

Sort dropdown drives `sortBy` state + `sortOrder` state (existing). Default: `sortBy='key'`, `sortOrder='asc'`. Changing sort resets page to 1. Column header click sort (existing `handleTableChange`) coexists — both update same state.
