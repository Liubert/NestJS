Add 3 new public methods to TranslationsService:

1. **bulkQualityCheck(projectSlug, nsSlug, keys: string[] | undefined, userId, userRole)**:
   - Call `requireProject` + `assertAccess` once at the top.
   - Find namespace by slug (same pattern as runQualityCheck).
   - If `keys` is undefined or empty array, query all key names from `keyRepo` where namespaceId matches: `const allKeys = await this.keyRepo.find({ where: { namespaceId: ns.id }, select: ['key'] })` then map to string[].
   - Iterate keys sequentially (NOT parallel — AI calls are rate-limited). For each key, wrap in try/catch:
     - Call `this.runQualityCheck(projectSlug, nsSlug, key, userId, userRole)` — reuses existing method which does its own access check, but that's fine for correctness. If perf matters later, can optimize.
     - On success: push `{ key, status: 'ok', results: <return value> }` to results array.
     - On error: push `{ key, status: 'error', error: err.message }` to results array.
   - Return `{ results }`.

2. **bulkMarkExpected(projectSlug, nsSlug, keys: string[], locale: string | undefined, userId, userRole)**:
   - Call `requireProject` + `assertAccess` once at the top.
   - Find namespace.
   - If locale is provided, iterate keys and call `this.markAsExpected(projectSlug, nsSlug, key, locale, userId, userRole)` per key, wrapping in try/catch (skip failures, count successes).
   - If locale is NOT provided: fetch all locales for project via `this.localeRepo.findBy({ projectId: project.id })`. For each key x locale combination, call markAsExpected, wrap in try/catch.
   - Return `{ marked: <success count> }`.

3. **bulkUpdateContext(projectSlug, nsSlug, updates: Array<{key: string, context: string}>, userId, userRole)**:
   - Call `requireProject` + `assertAccess` once at the top.
   - Find namespace.
   - For each update in the array, do `await this.keyRepo.update({ namespaceId: ns.id, key: update.key }, { context: update.context })`. Count affected rows (update returns UpdateResult with `affected`).
   - Sum affected counts. Return `{ updated: <total> }`.

All methods follow the existing `requireProject` + `assertAccess` pattern at the top. Import nothing new — all repos and services already injected.
