<objective>
Add a `guidance` text field to LocaleEntity so project admins can store per-locale translation guidelines (formality, plural rules, UI conventions). Pre-fill defaults for ~37 common locales. Surface the field in Admin UI locale modals, inject it into all AI prompts (translate, quality check, auto-translate), and pass it through MCP tools.

Purpose: AI translations and quality checks currently ignore locale-specific rules (e.g. formal "vi" in Ukrainian, informal "du" in Swedish). Locale guidance gives project owners control over translation style per language.
Output: Working end-to-end feature: DB column, entity, DTOs, service, controller, AI prompt injection, Admin UI, MCP tools.
