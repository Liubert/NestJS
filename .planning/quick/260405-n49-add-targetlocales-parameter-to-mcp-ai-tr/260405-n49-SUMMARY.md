# Phase quick Plan 260405-n49: Add targetLocales Parameter to MCP ai_translate Tool Summary

**One-liner:** Added optional `targetLocales` string-array parameter to `ai_translate` MCP tool with project-locale validation and silent filtering of unknown codes.

## What Was Built

The `ai_translate` tool in `mcp-server/src/tools/ai.ts` now accepts an optional `targetLocales` parameter. When provided, only locale codes that exist in the project's configured locales are sent to the backend. Unknown codes are silently dropped with a note line appended to the output. When the parameter is omitted, the tool behaves identically to before (translates to all non-default project locales).

## Decisions Made

- **callerLocales alias:** Destructured as `callerLocales` to avoid shadowing the computed `targetLocales` variable used in the API call.
- **Silent filtering:** Unknown caller-supplied locale codes are silently removed (not rejected with an error) per plan spec. A note line is appended to output only when locales were dropped.
- **Always fetch project locales:** Project locales are always fetched to enable validation even when `callerLocales` is provided.
