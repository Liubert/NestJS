2. Modify `sandbox.service.ts` `getDiff()` method signature to accept pagination and filter params:
   `getDiff(projectSlug, userId, role, page = 1, limit = 50, filters?: { namespace?: string; locale?: string; status?: string })`

   Refactor the raw SQL to:
   - Keep the existing CTE structure (production + sandbox)
   - Add a `diff` CTE that computes status (added/changed/deleted) via CASE expression
   - Add filter WHERE clauses for namespace/locale/status when provided
   - Use `COUNT(*) OVER()` as a window function to get total count without a separate query
   - Add `LIMIT $N OFFSET $M` at the end (offset = (page - 1) * limit)
   - Still count added/changed/deleted from the FULL diff (not just the page). Use three separate `COUNT(*) FILTER (WHERE ...)` aggregates in a wrapping CTE or compute them with conditional aggregation in a second lightweight query on the diff CTE.

   Approach for summary counts: Use a subquery/CTE approach that computes:
   ```sql
   WITH ... (existing CTEs),
   diff AS (
     SELECT ..., 
       CASE WHEN p.key IS NULL THEN 'added'
            WHEN s.is_deleted = true THEN 'deleted'
            ELSE 'changed' END AS status
     FROM production p FULL OUTER JOIN sandbox s ...
     WHERE ... (existing diff filter)
   ),
   filtered AS (
     SELECT * FROM diff
     WHERE ($namespace IS NULL OR ns_slug = $namespace)
       AND ($locale IS NULL OR locale = $locale)
       AND ($status IS NULL OR status = $status)
   ),
   counts AS (
     SELECT
       COUNT(*) AS total,
       COUNT(*) FILTER (WHERE status = 'added') AS added,
       COUNT(*) FILTER (WHERE status = 'changed') AS changed,
       COUNT(*) FILTER (WHERE status = 'deleted') AS deleted
     FROM filtered
   )
   SELECT f.*, c.total, c.added, c.changed, c.deleted
   FROM filtered f, counts c
   ORDER BY f.ns_slug, f.key, f.locale
   LIMIT $limit OFFSET $offset
   ```

   This way summary counts reflect the filtered total, entries are paginated, and it is a single query.

   Return type changes to:
   ```typescript
   {
     total: number; added: number; changed: number; deleted: number;
     entries: DiffEntry[];
     meta: { page: number; limit: number; total: number; totalPages: number; }
   }
   ```
   Build meta using `{ page, limit, total, totalPages: Math.ceil(total / limit) }`. The `total` at top level and in `meta.total` are the same value (filtered total count).
