**Schema (zod):**
- `projectSlug: z.string()` — required, project slug
- `namespace: z.string()` — required, namespace slug
- `entries: z.array(z.object({ key: z.string(), text: z.string().min(1), context: z.string().max(1000).optional() })).min(1).max(200)` — entries to translate
- `targetLocales: z.array(z.string()).optional()` — optional locale filter
- `skipQuality: z.boolean().optional().describe('Skip sync quality check; results queued for background worker (default: false)')` 

**Description (joined lines):**
```
'Translate, save to sandbox, and quality-check in one step.',
'Replaces the 3-step flow: bulk_ai_translate -> bulk_import -> check_entry_quality.',
'Saves translations directly to sandbox (not production).',
'With skipQuality=false (default): returns per-key per-locale quality scores inline.',
'With skipQuality=true: saves translations, queues quality check, returns immediately.',
'Max 200 entries per call.',
```

**Handler:**
1. Call `apiPost('/translations/ai-translate/bulk-and-save', { projectSlug, namespace, entries, targetLocales, skipQuality })`.
2. Format response:
   - Line 1: `Translated and saved {N} keys to sandbox ({namespace}) in project {projectSlug}`
   - Line 2: `Saved: {created} created, {updated} updated`
   - If quality results present (skipQuality=false):
     - For each key, for each locale: `  [{locale}] {score}/100 ({level}){comment ? ' -- ' + comment : ''}`
     - Add agent guidance block at end:
       ```
       Agent guidance:
       - green (85+): No action needed
       - yellow (60-84): Review optional — consider improving if context available
       - red (<60): Must fix — use set_translation to correct, then check_entry_quality to re-check
       ```
   - If qualityStatus === "queued":
     - `Quality check: queued (background worker will process within ~30s)`
     - `Use check_entry_quality per key to see results after processing.`
3. Return via `textResult()`.
4. Error handling: wrap in try/catch, return `errorResult(error)`.
5. Log via `logWrite('bulk_translate_and_save', { projectSlug, namespace, entryCount }, result)`.
