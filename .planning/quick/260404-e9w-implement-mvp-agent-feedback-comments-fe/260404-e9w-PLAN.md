         a. Rate limit check: COUNT(*) from agent_feedback WHERE user_id = currentUser.id AND created_at > NOW() - INTERVAL '1 hour'. If >= 10, throw HttpException('Rate limit exceeded: max 10 feedback items per hour', HttpStatus.TOO_MANY_REQUESTS) (import HttpException and HttpStatus from @nestjs/common since NestJS has no built-in TooManyRequestsException)
         b. If dto.projectSlug provided, look up project via projectRepo.findOne({ where: { slug: dto.projectSlug } }). If not found, throw NotFoundException. Extract projectId.
         c. Create entity: feedbackRepo.create({ ...dto without projectSlug, userId: currentUser.id, projectId (if resolved), isMcpToken: !!currentUser.isMcpToken })
         d. Return feedbackRepo.save(entity)
       - `async findAll(query: QueryFeedbackDto)`:
         a. Build QueryBuilder on agent_feedback aliased 'fb'
         b. leftJoin user (fb.user) and project (fb.project), addSelect user.email and project.slug
         c. Apply where clauses: category, reviewed, severity if provided. For projectSlug: join project, where project.slug = :slug
         d. orderBy fb.createdAt DESC
         e. skip/take from page/limit: skip = (page-1)*limit, take = limit
         f. Return { items: await qb.getMany(), total: await qb.getCount() } (or use getManyAndCount)
         Note: For getMany() to include joined fields, use relations or select the joined columns. Simpler: use qb.leftJoinAndSelect('fb.user', 'user').leftJoinAndSelect('fb.project', 'project') then map the response to include user.email and project.slug.
       - `async markReviewed(id: string, dto: ReviewFeedbackDto)`:
         a. Find by id, throw NotFoundException if missing
         b. Update reviewed and reviewerNote
         c. Return feedbackRepo.save(entity)
